### Requirements
- python 3.11.9
- pip 24.0

--- 

### Setup
#### 1. Tạo và active venv
#### 2. Tạo database "job5ing"
#### 3. Tạo file .env tại thư mục root (cùng cấp với .example.env), coppy các key từ file example và thay đổi các value tương ứng
#### 4. Cài các requirements
```bash
pip install -r requirements.txt
```

#### 5. Chạy dự án 
```bash
flask run
```
